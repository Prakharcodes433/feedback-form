# Guest Feedback Form

A sleek, responsive, and user-friendly feedback form designed for modern service environments. This project demonstrates clean HTML5 structure, CSS3 flexbox layouts, and modern UI/UX principles for web forms.

## Features

* **Responsive Design:** Fully optimized for desktops, tablets, and mobile devices.
* **Form Validation:** Built-in HTML5 validation for required fields and data types.
* **Modern UI:** Professional color palette with interactive hover states and shadows.
* **Accessible Layout:** Uses semantic HTML tags to ensure screen reader compatibility.

##  Technologies Used

* **HTML5:** Semantic structure.
* **CSS3:** Flexbox layout and custom styling.
* **JavaScript:** Linked for potential client-side logic.
